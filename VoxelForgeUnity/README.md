# Voxel Forge: порт на Unity 2022.3.62f3

Это порт на C# браузерной игры `voxel_forge_v0_93_59_water67_complete_mesh_guards.html` (WebGL2 + JS) для **Unity 2022.3.62f3** со встроенным рендер-пайплайном (Built-in RP).

Порт делался как можно ближе к оригиналу. Имена функций и полей JS сохранены, поэтому любой C#-метод находится в JS-исходнике поиском по имени. Числовая семантика JS тоже воспроизведена: `Math.imul`, `>>>`, `|0`, `Math.round`, порядок итерации `Map`/`Set`, стабильная сортировка. Поэтому мир с тем же seed генерируется так же, как в браузере.

## Как открыть и проверить в Unity

1. Установите редактор **Unity 2022.3.62f3** (через Unity Hub; подойдёт и другая 2022.3 LTS — Hub предложит открыть с ней).
2. Unity Hub → **Add → Add project from disk** → выберите папку `VoxelForgeUnity`.
   Первое открытие импортирует ассеты и компилирует шейдеры (1–3 минуты).
3. После компиляции Editor-скрипт сам:
   - создаёт сцену `Assets/Scenes/VoxelForge.unity` (пустую — игре объекты на сцене не нужны) и добавляет её в Build Settings;
   - ставит **Color Space = Gamma** (оригинал смешивает цвета и считает туман в гамма-пространстве), выключает MSAA,
     включает Run In Background и ландшафтную ориентацию для мобильных.

   Повторить вручную: меню **Voxel Forge → Apply Project Settings**.
4. Нажмите **Play** (или меню **Voxel Forge → Play**). Появится стартовый экран со списком миров:
   введите имя, нажмите «Новый Creator» или «Новый Survival» (или «Играть» у сохранённого мира), затем кликните по миру, чтобы захватить мышь.
5. Сборка: **File → Build Settings → PC, Mac & Linux Standalone** (или Android/iOS) → Build.
   WebGL не поддерживается: генерация и мешинг идут в фоновых потоках C#.

Что стоит посмотреть при проверке:
- Console без ошибок после импорта (шейдеры `VoxelForge/*` компилируются впервые именно в Unity).
- Статистика в левом верхнем углу HUD: FPS, число чанков, draw calls, треугольники.
- Дальность прорисовки — клавиши `[` / `]` или «Настройки» в паузе (Esc).

Нужен старый Input Manager (по умолчанию в 2022.3): `Active Input Handling = Input Manager (Old)` или `Both`.

```
Assets/VoxelForge/
  Scripts/
    Core/    JS-семантика (JsRuntime), JSON, OrderedMap/Set, данные, блоки, настройки, звук
    World/   хранение мира, свет (BFS), правила света, тики мира (жидкости, рост, огонь, падение)
    Gen/     ядро генерации мира (шум, климат, биомы, пещеры, руды, структуры) и gen-воркер
    Mesh/    мешер (greedy, AO/свет, спецформы, вода), работает в фоновых потоках
    Engine/  воркеры (потоки), стриминг чанков, кадр, ввод, загрузчик VoxelForgeGame
    Game/    игрок, физика, выживание, взаимодействие, правила блоков, дропы, мобы, транспорт, инвентарь
    Render/  загрузка чанков в GPU, регионы рендера, рендерер, эффекты, частицы, модели, атлас, миникарта
    UI/      IMGUI-замена DOM-интерфейса
  Resources/VoxelForge/
    Shaders/ шейдеры (террейн, x-ray, вода, depth-prepass, спрайты, сущности, частицы, линии, облака)
    *.json, *.bytes  данные оригинала (атласы, климат, структуры, виртуальные блоки)
  Editor/    настройка проекта (сцена, Build Settings, Gamma)
Tools/      проверки без Unity (не входят в проект — Unity папку Tools игнорирует):
  compile-check/  компиляция: mcs + заглушки и настоящий Roslyn + UnityEngine из NuGet
  parity-mesh/    мешер: JS-воркер vs C# MeshCore, побитово
  parity-light/   свет: JS-движок света vs C#, побитово
  parity-math/    JsMath vs Math.* в Node (V8), побитово
  headless/       вся игра под Mono без Unity: сценарий игрока + проверки
  audit/          результаты построчного аудита подсистем
```

## Рендер и производительность

- **Один CommandBuffer на кадр.** Камера рендерит пустой culling mask и только очищает экран, а все проходы JS `render()` записываются в CommandBuffer в исходном порядке. Порядок: небо, opaque/cutout (или x-ray), частицы, сущности, дропы, трещины, полупрозрачные, вода (depth-prepass + цвет), облака, обводка, предметы в руке.
- **Регионы 2×2 чанка.** Один `Mesh` на регион с перекрывающимися сабмешами (весь opaque, opaque по чанкам, весь cutout, cutout по чанкам). Видимый регион рисуется одним вызовом, частично видимый — по чанкам.
- **Advanced Mesh API.** Используются `SetVertexBufferParams/Data`, 16-битные индексы, если вершин не больше 65535, `MeshUpdateFlags` без пересчёта bounds и без валидации. Вершина террейна занимает 24 байта: позиция f32×3, UV half×2, тень f32, тайл и свет half×2.
- **Пул мешей**, ручные bounds, отсечение по фрустуму в JS-стиле (`updateFrustum`/`aabbVisible`) и иерархический сбор видимых чанков.
- **Фоновые потоки.** Генерация и мешинг идут в фоновых потоках, как web workers в оригинале. Результаты применяются в главном потоке с бюджетом времени на кадр.
- **Атлас.** Texture2DArray с точечной выборкой; `NEAREST_MIPMAP_LINEAR` эмулируется в шейдере.
- **Динамическое разрешение** (шаги 1/0.85/0.72/0.6/0.5) через RenderTexture с апскейлом. Включено по умолчанию, отключается в настройках.

## Сохранения

Сохранения и настройки лежат в `Application.persistentDataPath` (замена `localStorage`). Формат JSON совпадает с оригиналом.

## Отличия от оригинала

- Нет GPU timer query и occlusion query. Динамическое разрешение ориентируется на время кадра CPU.
- DOM-интерфейс заменён на IMGUI с теми же экранами и логикой слотов.
- WebAudio заменён процедурным синтезом `AudioClip`: те же события звука, звучание приблизительное.
- Кнопка «Выбор режима» не перезагружает страницу, а закрывает сессию и возвращает на стартовый экран.

## Что проверено без Unity

Unity в контейнере разработки нет, поэтому порт проверялся исполнением и сравнением с оригинальным JS:

| Проверка | Как | Результат |
|---|---|---|
| Компиляция | `Tools/compile-check/real-check.sh`: Roslyn C# 9 (как в Unity 2022.3) против настоящих сборок UnityEngine/UnityEditor из NuGet | runtime- и editor-скрипты компилируются без ошибок и предупреждений |
| Генерация мира | JS-ядро генерации в Node против C# под Mono, одинаковые seed | все чанки (блоки, метаданные, биомы, высоты) побитово совпадают |
| Математика | `Tools/parity-math`: `JsMath` (порт fdlibm из V8) против `Math.*` в Node, миллионы сэмплов | 0 расхождений; мир не зависит от libm платформы |
| Мешер | `Tools/parity-mesh`: 71 задача, 2.1 млн вершин, все типы блоков и форм | побитово совпадает |
| Свет | `Tools/parity-light`: 4354 команды правок, 592 снимка света всего мира | побитово совпадает |
| Аудит | 12 подсистем построчно против JS, состязательная перепроверка находок | 51 находка исправлена (`Tools/audit/AUDIT.md`) |
| Вся игра | `Tools/headless`: весь цикл игры под Mono с «живыми» заглушками Unity и сценарием игрока | см. `Tools/headless/last-run.log` |

Не проверено без Unity: компиляция шейдеров и картинка на экране. Это первое, на что стоит смотреть при открытии проекта.

Быстрые команды (из папки `VoxelForgeUnity`, нужны `mono`/`mcs`, для паритетов — `node` и путь к prettified JS оригинала):

```sh
sh Tools/compile-check/check.sh          # mcs + заглушки, секунды
sh Tools/compile-check/real-check.sh     # Roslyn + настоящий UnityEngine (скачивает пакеты NuGet)
sh Tools/headless/run.sh --frame-ms 6    # вся игра без Unity, ~20 минут
```
