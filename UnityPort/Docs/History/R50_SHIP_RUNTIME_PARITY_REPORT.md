## What R50 adds

R50 continues the R49 renderer/shipwreck work instead of replacing it.

- `Q6/P6` style detach: six-connected structure rooted at `SHIP_WHEEL`, source sailing cap **3000 blocks**, local block coordinates, water/air restoration at the former hull.
- `BB` controls in source coordinates with the exact source constants: acc 7, max 5, drag 1.3, turnAcc 1.1, turnDrag 2, turnMax .65, reverse .4.
- `c7` collision rejection order: yaw -> X -> Z.
- `Os/QB/v6` buoyancy constants: gravity 9.8, vertical drag 2, max vertical velocity 4. Retained sealed-air cells contribute displacement.
- `A7/g6` style retained-air/flood state with leak/outside floods and **3 flood cells per 200 ms tick**.
- `Ns/ks/Ni` style dynamic water carve around the moving hull: 4x4x3 sub-cell sampling, .45 velocity look-ahead, 120 ms throttle, `.35` position / `.06` yaw recarve thresholds, exact cached restoration of carved water.
- World water simulation consults the carved-water cache and cannot refill a reserved ship cell while the hull occupies it.
- `EE/Ss` style docked-ship ray selection and player body collision in ship-local coordinates.
- Creative and survival mining can break blocks on a docked moving ship; survival uses the existing source mining/tool/drop path.
- Block placement on a docked moving ship rebuilds only that ship's persistent GPU geometry.
- Door/gate/trapdoor interaction toggles the source open bit; a two-block door synchronizes both halves. Breaking either door half removes its pair.
- `C7/S6` style mob attachment: non-aquatic mobs standing on a ship retain a local pose, move with the hull and inherit ship delta-yaw.
- `w7/Lc` style vessel persistence now stores blocks, source pose, docked/riding state, retained-air (`holdCells`) and flooded (`floodCells`) cells.

## Renderer / performance architecture preserved

Movement and rotation do **not** rebuild ship voxel geometry. The vessel keeps a persistent mesh generated by the same `ChunkMesher` as terrain. Only local block edits/flood changes call `ReplaceGeometry`; ordinary motion calls `SetPose` and changes the draw matrix.

The static terrain shader remains the fast world-space shader. Moving ships use transform-aware ship shaders so the cost of a model matrix is not added to every static world vertex. Alpha order remains `world water -> ship water -> glass`.

Dynamic carve mutates only water/aquatic cells touched by the hull, not all visible chunks. The ordinary water tick respects reserved cells, avoiding immediate water refill through the moving hull.
