# Maincraft — однофайловый порт на WebGL2

Готовая игра: [`../maincraft.html`](../maincraft.html). Это один файл (~1.1 МБ): в нём код, воркеры и все текстуры.
Открывается двойным щелчком, сервер не нужен.

Код написан заново, а не скопирован из оригинала. Из оригинала взяты только данные: список блоков, их названия (ru/en),
текстуры, формы, константы освещения и затенения граней, а также набор биомов и деревьев.

## Сборка

```
python3 build.py            # нужен Pillow; результат пишется в ../maincraft.html
```

`build.py` собирает `tex/*.png` в один атлас. Он же применяет те же тонировки, что в оригинале (трава, листва, вода),
оставляет кадры анимации воды и морской травы и генерирует недостающие текстуры: двери и трещины при ломании.
Потом он вставляет исходники из `src/` в `src/index.html`.

## Устройство

| файл | что внутри |
|---|---|
| `blockdata.js`, `blocks.js` | таблица блоков → типизированные массивы (форма, непрозрачность, слой рендера, свет, коллизия) |
| `noise.js`, `biometable.js`, `worldgen.js` | генератор как в maincraft: континентальность/эрозия/странность → высота (те же сплайны), 3D-плотность на сетке 4×8×4 без летающих островов; биом выбирается по таблице мульти-шума Minecraft (температура, влажность, континентальность, эрозия, странность) на сетке 4×4 с «размытым зумом» Minecraft на границах — 50 биомов; реки, пещеры (cheese/spaghetti/noodle), руды, деревья (формы и таблица по биомам из maincraft), растительность, пещерные биомы |
| `mesher.js` | мешер секций 16³ в воркере: вершина 12 байт, AO и smooth lighting, все формы (ступеньки с углами, заборы, стены, панели, двери, люки, факелы, вода с усреднёнными углами), граф видимости секций |
| `world.js` | хранение секций, пул воркеров, свет (sky/block BFS, вертикальный sky без затухания, инкрементальные удаление и добавление), вода и лава, падающие блоки |
| `render.js` | WebGL2: texture array с мипмапами, lightmap, окклюзионный BFS и frustum culling по секциям, отсечение граней по направлению (квады секции сгруппированы по нормали, невидимые группы не рисуются, один multi-draw на секцию), порядок front-to-back / back-to-front, небо, солнце, луна, звёзды, облака 12×12×4 |
| `player.js`, `shapes.js`, `interact.js` | физика, рейкаст, правила установки и ломания, инструменты, дроп |
| `entities.js` | мобы как в maincraft (симуляция 20 Гц с интерполяцией, поиск пути A*, поведение каждого моба как в оригинале): свинья, корова, овца (6 цветов), курица, зомби, скелет, крипер, паук, эндермен, слизень (3 размера, делится), утопленник, лосось, акула; геометрия моделей MC, ИИ, спавн, бой, выпавшие предметы, стрелы |
| `craft.js`, `menus.js`, `ui.js`, `save.js`, `game.js` | крафт и печь, меню и инвентари, иконки, IndexedDB, игровой цикл |

## Управление

WASD — ходьба, Пробел — прыжок, F или двойной Пробел — полёт (творческий), Shift — присесть, Ctrl или двойное W — бег,
ЛКМ — ломать или бить, ПКМ — поставить или использовать, СКМ — взять блок, 1–9 или колесо — хотбар,
E — инвентарь, Q — выбросить, F3 — отладка, F5 — вид от третьего лица, F1 — скрыть интерфейс.
На телефоне: джойстик, свайп — обзор, тап — поставить или сломать (переключатель режима), удержание — ломать.
