# Own JS → WASM

Компилятор HTML+JavaScript в HTML со встроенным WebAssembly. Весь пользовательский
код становится WASM; на JS остаётся только тонкий слой для браузерных API
(DOM, WebGL, таймеры) — как `framework.js` у Unity.

`js-wasm-converter.html` — готовый конвертер (открыть в браузере).
Исходники собственных модулей — в `src/`, после правок: `node build.mjs`.

## Архитектура (по аналогии с Unity)

| Unity (C# → Web) | Здесь (JS → WASM) |
|---|---|
| Статические типы C# | Вывод типов по всей программе (`src/35-types.js`): `num` → `f64`, `bool` → `i32`, остальное — динамический `any` |
| IL2CPP: прямые вызовы, локальные переменные в регистрах | Статическое разрешение имён (`src/33-scope.js`): незахваченные переменные — локали WASM, захваченные — слоты записи окружения; известные функции вызываются напрямую `call` |
| Куча Unity в `WebAssembly.Memory` | Объекты, строки, окружения — WasmGC; сборкой занимается браузер. Целые ±2³⁰ — `i31ref` без выделения памяти |
| `.jslib` / `DllImport("__Internal")` | Импорты рантайма (`src/31-runtime.js`): `getProp`/`setProp`/`getIndex`/`setIndex`, `call0..call8` с передачей аргументов напрямую |

Конвейер: parse5 + acorn → анализ областей видимости → вывод типов →
генерация WASM (типизированное тело `t<id>` + адаптер `f<id>` для вызовов из JS)
→ HTML с загрузчиком.

Где тип вывести нельзя, генерируется тоже WASM, но с динамическими операциями
(как раньше). Генераторы и async-функции пока всегда на динамическом пути.

## Тесты

См. `tests/README.md`. `node tests/run-tests.mjs` — 156 программ, вывод JS и WASM
должен совпасть. `node tests/bench.mjs`, `node tests/game.mjs` — скорость.

## Результаты (headless Chromium 141, мс; меньше — лучше)

| Тест | JS | WASM v0.9 (исходный) | WASM сейчас |
|---|---:|---:|---:|
| locals (числовой цикл) | 13 | 1269 | 31 |
| noise (шум, Math) | 1.3 | 4131 | 24 |
| mesher (Uint8Array) | 1.3 | 631 | 27 |
| particles (объекты) | 3.9 | 842 | 413 |
| classes | 3.5 | 8547 | 951 |
| closures | 0.2 | 50 | 11 |
| strings | 7.1 | 1146 | 259 |

Игра Voxel Forge из репозитория: загрузка 55 с → ~5–6 с (JS — 0,8 с), FPS на
уровне JS, меню и работа идентичны.

Исходный конвертер не проходил 3 из 156 тестов (имя именованной функции-выражения,
имена функций в объектах с вычисляемыми ключами, рекурсия глубиной 2000);
текущая версия проходит все.

## Что дальше

1. Типы-записи: объекты с известной формой → WasmGC-структуры с полями `f64`
   (particles, classes, локальные объекты).
2. Тип «typed array»: элементы читаются/пишутся без упаковки.
3. Тип `int32` для целочисленной арифметики (индексы, битовые операции).
4. Классы как структуры с прямыми вызовами методов.
