    Экспериментальная версия. Поддержана часть JavaScript. Неподдержанные конструкции останавливают сборку. Переменные, строки, обычные объекты и плотные массивы хранятся в WASM. Сложные свойства, часть встроенных методов и DOM используют служебный JS. Ускорение страницы не гарантируется.
    Как открыть проект и что поддерживается

    Python и Node.js не нужны. Сохраните этот файл на компьютер и откройте его в браузере. Интернет для работы не требуется. Исходный HTML при конвертации не исполняется и никуда не отправляется.

    Один HTML можно открыть, перетащить или вставить в редактор. Если он использует локальные JS-файлы или модули, выберите папку проекта и затем нужный HTML в списке. Для плоского проекта можно выделить HTML и все JS одновременно. Браузер видит только выбранные вами файлы; CSS и картинки в результат не встраиваются.

    Есть классы и приватные поля, замыкания, деструктуризация, optional chaining, try/catch/finally, async/await, генераторы, for await, DOM и события. Модули поддерживают import/export, default, повторный экспорт, живые привязки, пространства имён и синхронные циклы. Есть top-level await и import("./file.js") со строковым литералом.

    Пока отсутствуют eval/Function и новый JS во время работы, вычисляемый путь import(), import maps, асинхронные циклы модулей, using, with и полная совместимость с ECMAScript. Сетевые скрипты, атрибуты script async/defer/nomodule и вложенные HTML в iframe отклоняются. Все найденные зависимости должны успешно скомпилироваться, включая ленивые импорты.

    Нужны WebAssembly GC, reference types и exception handling, Web Workers и FileReaderSync. Входные файлы — UTF-8, до 8 МБ каждый; до 256 модулей и 32 МБ исходников модулей. Одна сборка ограничена 30 секундами. Скачанный результат содержит WASM внутри; при переносе внешних ресурсов их ссылки нужно сохранить. Для страниц с CSP потребуется разрешить загрузчик и WASM.

    Исходники и лицензии зависимостей

    Генератор WASM, связывание модулей и бинарный кодировщик написаны для этого проекта. Acorn разбирает синтаксис JS, parse5 — HTML. Готовый JS → WASM компилятор и встроенный JS-движок не используются.
