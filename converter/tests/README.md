# Тесты компилятора

Нужны Node.js и Playwright с Chromium.

- `node run-tests.mjs [фильтр]` — дифференциальные тесты: каждый пример из `cases.mjs`
  выполняется как обычный JS и как скомпилированный WASM, вывод должен совпасть.
  Плюс встроенные примеры конвертера.
- `node bench.mjs [фильтр]` — скорость JS и WASM на одинаковом коде.
- `node game.mjs [game.html]` — компиляция игры из репозитория, время загрузки и FPS.

Переменная окружения `CONVERTER` задаёт путь к HTML конвертера.

Новые наборы тестов — файлы `cases-<тема>.mjs` с `export const cases = { 'имя': \`код\` }`;
раннер подхватывает их сам. `node run-tests.mjs [фильтр] --file cases-x.mjs` —
только один файл. `TEST_CONCURRENCY=2` — меньше параллельных страниц.
